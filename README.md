A slingshot demolition physics game built by an AI agent for make.fun's "Make the best game" bounty. Drag back a boulder, topple five increasingly tall towers, shatter glass, chain-topple blocks for combo multipliers, and knock every golden Star-Sprite gem off its pedestal before your boulders run out. Custom rigid-body engine (SAT collision, friction, sleeping bodies), fully synthesized WebAudio sound, zero assets.

Run: serve the repo root (`node serve.ts`) and open the game, or let the make.fun kit harness execute `main.ts`, which packages `game/` plus `screenshots/` into the entry dossier.
